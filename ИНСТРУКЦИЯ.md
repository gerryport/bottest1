# 🤖 Telegram Бот Верификации

Полнофункциональный бот для верификации пользователей с загрузкой селфи и паспорта.

## ✨ Функциональность

✅ **Кнопка подачи верификации** - красивая кнопка для начала процесса  
✅ **Загрузка документов** - селфи и фото паспорта  
✅ **Прогресс-бар** - визуальное отображение загрузки (0-100%)  
✅ **Статус сообщения** - "На проверке", "Ожидайте"  
✅ **Удобный интерфейс** - кнопки и четкие инструкции  

---

## 🚀 Быстрый старт

### 1️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2️⃣ Получение токена бота

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте команду `/newbot`
3. Следуйте инструкциям BotFather
4. Скопируйте полученный **токен**

Пример токена: `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11`

### 3️⃣ Узнайте свой ID Telegram

1. Найдите бота **@userinfobot**
2. Отправьте ему любое сообщение
3. Получите свой числовой ID (например: `123456789`)

### 4️⃣ Настройка бота

Откройте файл `verification_bot.py` и замените:

```python
# Строка 156 - ваш токен
BOT_TOKEN = "123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11"

# Строка 160 - ваш ID для получения заявок
ADMIN_ID = "123456789"
```

### 5️⃣ Запуск бота

```bash
python verification_bot.py
```

Вы должны увидеть:
```
🤖 Бот запущен...
```

## 📋 Что делает бот

### Процесс верификации пользователя:

1. **Начало** 👋
   - Пользователь пишет `/start`
   - Видит приветственное сообщение
   - Нажимает кнопку "✅ Начать верификацию"

2. **Загрузка селфи** 📸
   - Бот просит загрузить фото себя
   - Показывает требования (освещение, без фильтров)
   - Отображает прогресс-бар загрузки
   - Показывает "✅ Успешно"

3. **Загрузка паспорта** 📄
   - Просит загрузить фото паспорта
   - Показывает прогресс загрузки
   - Отправляет статусное фото "На проверке"

4. **Уведомление админа** 📬
   - Вы получаете сообщение о новой заявке
   - С информацией о пользователе и загруженных документах

### Изменить текст приветствия

Найдите в коде функцию `start()` и отредактируйте переменную `welcome_text`:

```python
welcome_text = (
    f"👋 Привет, {user.first_name}!\n\n"
    "Ваш текст здесь"
)
```

### Изменить требования к селфи

Найдите функцию `start_verification()` и отредактируйте текст:

```python
await query.edit_message_text(
    text="📸 Отлично! Начнем с селфи.\n\n"
         "Ваши требования здесь"
)
```

### Изменить время проверки

Найдите статус сообщение и измените текст:

```python
await update.message.reply_photo(
    photo="...",
    caption="⏳ Ваша верификация на проверке\n\n"
           "Проверим в течение 12 часов"
)
```

## 🐛 Решение проблем

### ❌ "Ошибка: Установите BOT_TOKEN"
- Проверьте, вставили ли вы токен в переменную `BOT_TOKEN`
- Убедитесь, что скопировали весь токен полностью

### ❌ "Бот не отвечает"
- Проверьте интернет соединение
- Убедитесь, что все зависимости установлены: `pip install -r requirements.txt`
- Проверьте корректность токена

### ❌ "Ошибка при загрузке фото"
- Убедитесь, что это jpg/png изображение
- Размер фото должен быть < 20 MB
- Попробуйте загрузить еще раз

### ❌ "Админ не получает уведомления"
- Проверьте, верно ли указан ADMIN_ID
- Убедитесь, что вы начали диалог с ботом (@userinfobot)
- Проверьте прав доступа в Telegram
